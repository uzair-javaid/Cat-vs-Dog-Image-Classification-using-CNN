# 🐶🐱 Cat vs Dog Image Classification using CNN

This project is a **Deep Learning-based Image Classification** model that distinguishes between **cats and dogs** using a **Convolutional Neural Network (CNN)** built with TensorFlow and Keras.

---

## 🚀 Project Overview

The model is trained on a **Kaggle dataset ** consisting of cat and dog images.
It processes images, learns visual features, and predicts whether a given image is a **cat 🐱** or **dog 🐶** with confidence scores.

---

## 🧠 Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Matplotlib
* ImageDataGenerator (for preprocessing and augmentation)

---

## 📂 Dataset


* Folder Structure:

  ```
  dataset/

  │   └── dogs/
  └── test/
      ├── cats/
      └── dogs/
  ```

---

## ⚙️ Model Architecture

* **Conv2D** layers for feature extraction
* **MaxPooling2D** for dimensionality reduction
* **Flatten + Dense** layers for classification
* **Dropout** for regularization
* **Sigmoid** activation for binary output (Cat/Dog)

---
